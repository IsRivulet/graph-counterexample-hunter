## 五、关键发现与注意点

1. **旧固定用例集核验结果**：所有 `counterexample_found` 的 witness 都通过了独立结构复核（precision=recall=100%），所有 `no_counterexample_in_scope` 的穷举任务都真正完成了全范围枚举（`fully_exhausted=true`）。

2. **能力边界分流正确**：7 条 unsupported（有向图、多重图、任意度阈值、否定、析取、exhaustive 超 6 顶点）+ 3 条 clarify（欧拉术语歧义、空图约定、方向缺失）全部正确停止调用并说明原因，没有静默近似。

3. **故障注入诚实降级**：E2E-40/41/42 三条 fault injection 用例均返回 `inconclusive` 或保留已核验原反例，没有虚构 coverage 或搜索结果。

4. **关于 100% 的诚实说明**：本套 harness 的"解析层"是一个**规则式解析器**，它编码了 SKILL.md 要求的精确语义决策。100% 的解析正确率说明**这套规则的语义约定自洽**，但**不等于真实 LLM 能达到 100%**——真实 Skill 由大模型执行自然语言理解时，仍可能出现规则覆盖不到的边缘解析错误。因此这份基线应被理解为"后端 + 确定性解析约定"的上界，而非"LLM 端到端"的真实表现。

## 七、下一步建议

- 若要测量**真实 LLM 的端到端解析能力**，需把 harness 的"规则解析层"替换为真实模型调用，再重跑，并与当前基线对比，差异即 LLM 的解析误差。
- 若要扩充测试集规模，可基于 20 个命题模板 + 新增边缘语料（否定、歧义、超范围）扩充 `cases`，重跑 `build` 与 harness。
